# AGY Beautify（Antigravity 全能美化套件 · 增强版）

将系统字体与字重定制、2,750+ 词条深度汉化、全屏 Token 与美元监控台、液态玻璃引擎、深浅色主题、自定义壁纸库、上下文自动压缩与效率模块整合为一个零依赖原生 Antigravity 2.0 插件。

## 快捷入口

- **底栏 `✦ xx%` 快捷浮窗**：实时切换深浅色、液态玻璃/轻柔磨砂/纯净实体、一键预设、壁纸、**本机系统字体与字重（100–900）**；内置「上下文压缩」卡片，支持手动 `⚡ 立即压缩` 以及拖动阈值进度条（默认 `80%`，可调 `40%–95%`）在上下文超阈值且本轮对话结束后自动执行 `/compact`。
- **左侧导航栏「监控台」**：位于左侧 `自定义` 下方，分「总览」「工具与耗时」「全部会话」三视图展示总 Token、美元、缓存节省、14 天趋势、Token/耗时环形图、20 周活跃度热力图、工具调用与终端命令 TOP 10、技能与项目分布，以及可搜索排序的会话卡片。
- **侧边栏美化控制台**：[AGY Beautify](sidecar://agy-beautify/beautify_hub/)（包含完整系统字体搜索/筛选、界面字体与代码等宽字体分别定制、实时排版预览）。
- **管理插件开关**：[AGY Beautify](customization://agy-beautify)
